# Kashmir Mobile Shop — React + TypeScript

A responsive sample storefront for Kashmir Mobile Shop in Dhari Sanghi, Rahim Yar Khan.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build, run `npm run build`.

## Customize

- `src/App.tsx`: sample product records, categories, contact flow, and page components.
- `src/styles.css`: visual design, responsive layout, and hover animation.
- `public/assets/`: illustrative images. Replace with real inventory photos.
- Set `WHATSAPP_NUMBER` in `src/App.tsx` to the shop's verified number in international format without `+` or spaces (example: `923001234567`).

The listed phones, prices, availability, and conditions are placeholders until the shop verifies them. The WhatsApp actions show a notice until a number is supplied.
